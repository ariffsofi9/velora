# VELORA
### AI Smart Inventory Management for F&B Businesses

**VELORA** is a Flutter-based mobile application designed to help cafés, bakeries, and restaurants manage inventory, monitor stock, organize recipes, and improve daily operations through AI-assisted features.

## Key Features
- Inventory and ingredient management
- Stock monitoring and activity tracking
- Secure Owner and Staff role management
- AI-powered recipe suggestions (planned integration)
- Recipe discovery and saved recipes
- Menu management and ingredient usage tracking
- Firebase Authentication and Cloud Firestore integration

## Technology Stack
- **Frontend:** Flutter & Dart
- **Backend:** Node.js (Secure HTTPS API)
- **Database:** Firebase Cloud Firestore
- **Authentication:** Firebase Authentication
- **AI:** Groq API (planned)
- **Platform:** Android, iOS & Tablet

## Development Status

**Currently in active development.**

Core backend security, inventory workflows, and recipe-related components have been implemented and tested offline. Live Firebase integration, physical-device testing, and production deployment are still pending.

## Project Goal

To develop a secure, intelligent, and user-friendly inventory management application that helps F&B businesses reduce manual work, improve stock visibility, and make better kitchen decisions.
